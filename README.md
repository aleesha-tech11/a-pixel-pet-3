# 🐾 a pixel pet

I built a website where you can get pixel figures as pets and u can name it.
Feed it and take it outside too.
I wanted to try pixel art but the plan backfired so i switched to something simpler and just naming and selecting was enough.

##languages used

- HTML5
- CSS3
- JavaScript 
## features
.You select a pet by pressing lets get u a pet it opens some options and you select and name it it also shows hunger and energy levels.
## How to play
uhh simple its just html and css so u can use it in a browser any time.
